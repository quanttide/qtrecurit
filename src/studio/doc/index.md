# qtrecurit Studio 页面与组件规划

qtrecurit Studio 是候选人的透明窗口——让候选人用同一套标准、同一套数据看自己。当前只规划一个核心页面：**个人考评记录**。

## 页面规划

| 页面 | 路由 | 内容 |
|------|------|------|
| 个人考评记录 | `/candidate/:token` | 凭查询凭证查看选拔过程和结果：评估记录（考核分层、问卷分析）与信任记录（历史行为、背调、推荐信） |

## 组件规划

- 候选人卡片：基本信息、序列轨道、当前状态
- 状态徽章：候选人状态流转（投递 → 问卷 → 实战 → 评估 → 背书）
- 问卷条目：问题与 AI 分析摘要
- 信任记录条目：历史行为、背调、推荐信
- 档案时间线：选拔过程的关键节点与结果

## 数据模型

与 Provider API schema 同源，保证评估字段与信任字段同构契约：

- `candidate`：候选人档案、状态流转
- `assessment`：问卷、实战、评估过程与结果
- `criteria`：考核分层、序列轨道（支撑展示，已有 `models/criteria.dart`）
