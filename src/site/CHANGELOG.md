# Changelog

## [0.2.0] - 2026-09-05

### 变更

- 首页重定位为招聘门户「量潮和它的朋友们的招聘门户」：按就业类型与雇主两个维度导流，不再承载量潮公司简介/主营业务（已并入量潮雇主页）
- 岗位卡片新增「申请方式 →」入口，锚点直达雇主页应聘方式区块（`/employers/:id#apply`）
- 雇主相关信息（实习报名/考核、兼职流程）从岗位页移至量潮雇主页，岗位页只做岗位浏览
- 岗位卡片新增「申请方式 →」锚点链接；雇主卡片去除下划线
- 导航重构为「首页 / 岗位 / 雇主」：岗位按就业类型与雇主两个维度均可访问
- `/intern`、`/parttime` 合并入 `/positions`：原实习报名/考核、兼职提成/流程改为按就业类型筛选条件展示；简历求职信要求与考核详情迁至 `/positions/application`、`/positions/assessment`
- 新增岗位一览页 `/positions`：按雇主分组展示全部在招岗位，支持按就业类型筛选（`?type=`）

### 新增

- 新增合作雇主页面组：`/employers` 列表页 + `/employers/:employerId` 雇主独立页（链接可直接转发给雇主自行传播）
- 岗位数据新增 `employerId`（合作雇主岗位）与 `salary` 字段；新增「全职」就业类型与「科研类」类目
- 首个合作雇主：大连医科大学课题组（心血管与神经免疫方向，科研助理实验/生信各 1 名），独立页为 `/employers/dmu-cardiovascular`
- 新增雇主数据文件 `src/data/employers.ts`：雇主简介、投递邮箱与邮件主题格式按雇主配置

## [0.1.2] - 2026-08-30

### 新增

- 考核过程补充关键信息：填写问卷后邀请进群，考核最长不超过一个月
- 课题申请渠道明确：hr 邮箱提交，可申请 1 次、最多迭代 3 次
- 新增「评估标准与结果」章节：协作表现四维度（主动性/交付质量/沟通专业性/同伴评价）与通过/未通过结果
- 示例课题指路：众包平台发布的任务即示例课题

### 变更

- 流程第 5 步拆分：评估标准与结果独立成节，流程列表只留一句话
- 「如何获取公司支持/学习支持」合并为「支持资源」，统一代金券口径
- 「小结」压缩并入「我们对考核过程的预期」，消除重复
- 语气中性化：移除威慑性表述
- 引号统一为直角引号
- Intern 页考核摘要对齐五步流程

## [0.1.1] - 2026-08-30

### 新增

- 考核机制页新增「从「学生心态」到「乙方心态」」章节：不迎合出题人，以专业乙方姿态汇报课题改进与需求理解，双方是平等的契约关系
- 代金券新增一对一调研用法，附向甲方调研的提问方法

### 变更

- 「我们对考核过程的预期」引入「自然淘汰」口径：中途退出或无行动被清退即自然淘汰，真实的工作困难足够淘汰大部分不合格候选人

## [0.1.0] - 2026-08-25

正式发布。自 0.1.0-rc.2 无新增变更：

### 变更

- 实习页考核方式展开为四步流程：了解动态 → 制定课题 → 申请与提交 → 甲方评估（可独立或组队，推荐组队）
- 考核机制页新增「具体的考核过程」章节
- 明确证明与推荐信发放机制：评估通过后进入招聘入职环节发放；未通过面试但工作成果被认可，仍以标准化推荐信认证；实训、众包、课堂为保底路径
- 公司支持机制改为众包平台（crowd.quanttide.com）：真实任务明码标价，代金券/现金按身份选择，任务完成计入考核证明
- 新增「如何获取学习支持？」章节：课堂为培养体系中心，课程与考核同源，含问题驱动学习法与支持闭环
- 众包段改为阶梯路径表述：任务源自实训体系、精心设计，可先完成任务再升级为自己的课题
- 「我们对考核过程的预期」改为建设性视角：每阶段提供路径与支持，认可的工作成果以推荐信认证，保底路径仍在成长路径上
- 协作表现提升为考核重点，交付降为次要参考
