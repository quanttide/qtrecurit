# Changelog

## [Unreleased]

### 变更

- 实习页考核方式展开为四步流程：了解动态 → 制定课题 → 申请与提交 → 甲方评估（可独立或组队，推荐组队）
- 考核机制页新增「具体的考核过程」章节
- 明确证明与推荐信发放机制：评估通过后进入招聘入职环节发放；未通过面试但工作成果被认可，仍以标准化推荐信认证；实训、众包、课堂为保底路径
- 公司支持机制改为众包平台（crowd.quanttide.com）：真实任务明码标价，代金券/现金按身份选择，任务完成计入考核证明
- 新增「如何获取学习支持？」章节：课堂为培养体系中心，课程与考核同源，含问题驱动学习法与支持闭环
- 众包段改为阶梯路径表述：任务源自实训体系、精心设计，可先完成任务再升级为自己的课题
- 「我们对考核过程的预期」改为建设性视角：每阶段提供路径与支持，认可的工作成果以推荐信认证，保底路径仍在成长路径上
- 协作表现提升为考核重点，交付降为次要参考
