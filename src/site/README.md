# qtrecurit Site

量潮招聘官网（对外招聘门户）：招聘启事与招聘数据的公开窗口。

## 定位

- **招聘启事**：岗位要求、报名方式、求职信与简历指南——与招聘政策（问卷、轨道、序列）同源
- **招聘数据公开**：投递统计、岗位分布、招聘动态看板

官网（qtweb）「加入我们」页面跳转至此，不再内嵌维护招聘内容。

## 页面

| 路由 | 内容 |
|------|------|
| `#/` | 招聘看板：投递统计、岗位分布、招聘动态 |
| `#/join` | 加入我们：公司简介、招聘要求、报名方式、求职信与简历指南 |

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 生产构建
npm run lint     # ESLint 检查
```
