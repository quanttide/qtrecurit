# ROADMAP

现状 vs 愿景的差距分析见 [`docs/gap-analysis.md`](docs/gap-analysis.md)。

---

## 总体状态

当前实现本质是一个 **邮件采集与分类工具集**（ETL 层），完成的是招聘系统的数据底座：

```
邮件 → 拉取 → 分类 → 按候选人整理 → 统计报告
 ✅      ✅     ✅        ✅              ✅
```

愿景要求的是在这之上构建的应用层：

```
Pipeline 看板 → 岗位管理 → 笔试管理 → 协作评价 → 飞书集成 → 分析导出
   ❌           ❌          ❌         ❌         ❌         ⚠️
```

愿景中约 45 个功能点，已完全实现约 8 个（18%），未实现约 33 个（73%），最大缺口在应用层。

## 按阶段规划

### Phase 1 — 核心管道（MVP）

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **Pipeline 看板** | 高 | 仅有 CLI 和 JSON 文件，无可视化看板 |
| **阶段状态流转** | 高 | 6 阶段（新投递→已联系→笔试已发→笔试已收→评估中→面试→Offer/关闭）未在代码中建模 |
| **岗位管理** | 高 | 无岗位 CRUD、无岗位与候选人关联 |
| **按岗位+阶段+学校过滤** | 中 | 仅有 CLI audit 脚本按分类过滤邮件 |
| **标签系统** | 中 | 愿景中的 IMPORTANT/REPLIED/FLAGGED/FORWARD 标签和自定义标签均无 |
| **沟通时间线** | 中 | 邮件已按候选人聚合，但无可视化时间线 UI |
| **多岗位投递** | 中 | 同一候选人投递多个岗位无法在系统中体现 |

### Phase 2 — 笔试与协作

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **笔试模板管理** | 高 | `docs/questions/` 有静态 Markdown，但无模板 CRUD、评分标准 |
| **笔试实例管理** | 高 | 无 ExamInstance 模型，无轮次管理、截止日期、催交 |
| **多轮考核版本化** | 中 | 钟涛的 3 轮考核场景无法跟踪 |
| **评估人分配** | 中 | 无张果/刘婧怡等评估人分配机制 |
| **评价录入** | 中 | 结构化表单+自由文本评价未实现 |
| **评价后自动推进** | 中 | "通过→面试，不合格→关闭"自动流转未实现 |
| **附件按类别归档** | 低 | 简历附件自动移到 `attachments/resume/` 目录 |

### Phase 3 — 自动化与深度集成

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **飞书邮件自动同步** | 高 | 当前通过 lark-cli 手动拉取，无定时/事件驱动同步 |
| **飞书群聊通知** | 中 | 新投递/笔试截止等场景无 IM 通知 |
| **飞书面试日历** | 中 | 无日历 API 集成 |
| **数据分析看板** | 中 | 仅有 CLI 脚本输出的静态 Markdown/JSON，无可交互看板 |
| **CSV/Excel 导出** | 中 | 无导出功能 |
| **飞书文档存储** | 低 | 无云盘 API 集成 |
| **自动去重检测** | 低 | 重复投递场景无检测逻辑 |

### 基础架构缺失

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **Web 应用** | 高 | 技术选型推荐 React，实际为零 |
| **后端 API** | 高 | 技术选型推荐 FastAPI，实际为零 |
| **数据库** | 高 | 愿景用 PostgreSQL，现在只靠 JSON 文件 |
| **数据模型** | 高 | Candidate / Position / Application / ExamTemplate / ExamInstance / Communication / Evaluation — 一个都没在代码中定义 |
| **角色权限** | 中 | 无 HR/评估人权限划分 |
| **Offer 管理** | 中 | Offer 模板、发送、跟进确认无 |
| **转岗推荐** | 低 | 系统推荐+一键转岗无 |
| **审批流程** | 低 | 飞书审批（Offer 审批）无 |
| **机器人通知** | 低 | 无机器人提醒（笔试截止、新投递） |
